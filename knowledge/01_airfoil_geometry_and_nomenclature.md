# 翼型几何与命名体系

> 参考来源：Abbott, I. H., & Von Doenhoff, A. E. (1959). *Theory of Wing Sections*. Dover Publications. Chapter 1-2.
> Anderson, J. D. (2017). *Fundamentals of Aerodynamics* (6th ed.). McGraw-Hill. Chapter 4.

## 1. 翼型基本几何定义

翼型（Airfoil）是机翼的横截面形状，是产生气动力的核心几何。

### 1.1 关键几何术语

- **前缘（Leading Edge, LE）**：翼型最前端的点，通常为圆弧形。前缘半径（Leading Edge Radius）直接影响失速特性。
- **后缘（Trailing Edge, TE）**：翼型最后端的点，通常为尖锐形状（库塔条件要求）。
- **弦线（Chord Line）**：连接前缘和后缘的直线段。
- **弦长（Chord Length, c）**：弦线的长度，是翼型的基本尺度参考。
- **中弧线（Mean Camber Line）**：上下表面之间等距点的连线。如果中弧线与弦线重合，则为对称翼型。
- **弯度（Camber）**：中弧线与弦线之间的最大距离，通常以弦长百分比表示。如弯度为2%表示最大弯度为0.02c。
- **厚度（Thickness）**：上下表面之间的垂直距离。最大厚度（Maximum Thickness）以弦长百分比表示。
- **最大弯度位置（Position of Maximum Camber）**：最大弯度点沿弦向的位置，以弦长百分比表示。
- **最大厚度位置（Position of Maximum Thickness）**：最大厚度点沿弦向的位置。

### 1.2 翼型坐标系

翼型坐标通常以弦长归一化表示：
- x/c = 0 为前缘
- x/c = 1 为后缘
- y/c > 0 为上表面
- y/c < 0 为下表面

上表面坐标从后缘沿上表面到前缘排列，下表面坐标从前缘沿下表面到后缘排列。

## 2. NACA 4位数翼型系列

### 2.1 命名规则

NACA 4位数系列由美国国家航空咨询委员会（National Advisory Committee for Aeronautics）在1930年代发展，是最早的系统化翼型族之一。

以 **NACA MPXX** 表示：
- **M**（第1位）：最大弯度，以弦长百分比表示。M=0时为对称翼型。
- **P**（第2位）：最大弯度位置，以弦长十分之几表示。P=4表示最大弯度在40%弦长处。
- **XX**（第3-4位）：最大厚度，以弦长百分比表示。XX=12表示最大厚度为12%弦长。

**示例：NACA 2412**
- 最大弯度 = 2% 弦长
- 最大弯度位置 = 40% 弦长
- 最大厚度 = 12% 弦长

### 2.2 厚度分布公式

NACA 4位数翼型的厚度分布由以下多项式定义（Abbott & Von Doenhoff, 1959, p.113）：

$$y_t = 5t \left[ 0.2969\sqrt{x} - 0.1260x - 0.3516x^2 + 0.2843x^3 - 0.1015x^4 \right]$$

其中 $t$ 为最大厚度比（如0.12），$x$ 为归一化弦向坐标（0到1）。

注意：原始公式在后缘处（x=1）厚度不严格为零（约为 $y_t = 0.0021t$），某些改进版本将最后一项系数修改为 -0.1036 以确保后缘闭合。

### 2.3 中弧线方程

对于弯度为 $m$、最大弯度位置为 $p$ 的翼型：

$$y_c = \begin{cases} \frac{m}{p^2}(2px - x^2), & 0 \leq x \leq p \\ \frac{m}{(1-p)^2}[(1-2p) + 2px - x^2], & p \leq x \leq 1 \end{cases}$$

### 2.4 上下表面坐标

$$x_U = x - y_t \sin\theta, \quad y_U = y_c + y_t \cos\theta$$
$$x_L = x + y_t \sin\theta, \quad y_L = y_c - y_t \cos\theta$$

其中 $\theta = \arctan(dy_c/dx)$ 为中弧线的局部倾斜角。

## 3. 其他NACA翼型系列简介

### 3.1 NACA 5位数系列
- 提供更多的弯度分布控制
- 命名更复杂，如NACA 23012
- 设计升力系数可以更高

### 3.2 NACA 6系列（层流翼型）
- 如NACA 64₁-212
- 通过精心设计压力分布来维持层流
- 最大厚度位置后移（40-50%弦长）
- 在理想条件下可显著降低摩擦阻力
- 但对表面粗糙度和制造精度要求极高

## 4. 翼型几何参数对性能的定性影响

| 参数 | 增大时的影响 |
|------|------------|
| 弯度 | Cl↑, Cd↑, |Cm|↑, 零升攻角变负 |
| 厚度 | 结构强度↑, 形阻↑, 前缘半径↑, 低Re下Cl_max可能↑ |
| 最大弯度位置后移 | 后装载分布, 有利于层流维持 |
| 最大厚度位置后移 | 顺压梯度区延长, 有利于层流但逆压梯度更陡 |
| 前缘半径增大 | 失速更温和, 但高速阻力↑ |
